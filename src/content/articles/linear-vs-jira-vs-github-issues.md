Project management tools for engineering teams have diverged sharply. Linear focuses on speed and developer experience. Jira is the enterprise behemoth. GitHub Issues lives where your code already is.

## At a Glance

| Feature | Linear | Jira | GitHub Issues |
|---------|--------|------|---------------|
| **Speed** | Instant | Sluggish | Fast |
| **Keyboard-first** | Excellent | Mediocre | Good |
| **Roadmap view** | Built-in | Via plugins | Projects Beta |
| **Workflow automation** | Powerful rules | Complex automation | GitHub Actions |
| **API** | GraphQL | REST + GraphQL | REST + GraphQL |

## Pricing

**Linear**: Free for up to 10 users. $8/user/mo for Standard (unlimited teams). $14/user/mo for Premium.

**Jira**: Free for up to 10 users. Standard starts at $7.16/user/mo but real costs run higher with add-ons. Data Center is $13,600+/year for 100 users.

**GitHub Issues**: Included in free GitHub accounts. Organizations get Projects boards starting at $4/user/mo (Team plan).

## Developer Experience

**Linear** is the clear winner here. It's designed for speed — keyboard shortcuts for everything, quick creation via command palette, and a snappy UI that feels native. Engineers who try Linear rarely want to go back to Jira.

**GitHub Issues** has improved dramatically with Projects v2. The tight integration with pull requests and code is its superpower — you can reference issues from commits, link PRs automatically, and close issues with merge commits.

**Jira** has the richest feature set (epics, sprints, story points, advanced roadmaps) but the UX is heavy. It's powerful if you need all those features; frustrating if you don't.
